# SOGL Engine

A lightweight graphics engine built with C++ and modern OpenGL. The project focuses on real-time rendering techniques and a clean, minimal API suitable for experimentation, learning, and building small-scale graphics applications.

## Preview

![SOGL Engine Preview](https://github.com/adarshcat/Sogl-Engine/raw/main/image.png)
![SOGL Engine Preview](https://github.com/adarshcat/Sogl-Engine/raw/main/video.gif)

## Features

- Model loading
- Directional lighting
- Basic shadow mapping
- Screen-space ambient occlusion (SSAO)
- Skybox rendering
- Image-based lighting (IBL)
- Bloom
- FXAA post-processing

## Build & Requirements

Language: C++17  
Graphics API: OpenGL 4.5

The engine relies on libraries that must already be installed on the system:

- opengl32
- glew32
- glfw3
- assimp
